A program that draws one deterministic single-page newspaper front page
(1024x1024 PNG) summing up the world's news of Tuesday 24 November
2026: 45 source-checked stories in 7 regions, led by Jensen Huang's
reinstatement as Nvidia CEO and the market surge that followed.
Standard library only; glyphs come from the pre-rendered `atlas.bin`,
so it needs no network and no installed fonts at run time.

## Run it

```
python3 main.py
```

Writes `out/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
